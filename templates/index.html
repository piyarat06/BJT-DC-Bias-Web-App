Voltage-Divider: VTH = VCC·R2/(R1+R2), RTH = R1·R2/(R1+R2), IB = (VTH−VBE)/(RTH+(β+1)RE), IC = β·IB, IE = (β+1)·IB, VE = IE·RE, VB = VE+VBE, VC = VCC−IC·RC, VCE = VC−VE

Fixed Bias: VTH = VCC, RTH = RB, IB = (VCC−VBE)/RB, IC = β·IB, IE = (β+1)·IB, VE = 0, VB = VBE, VC = VCC−IC·RC, VCE = VC

Emitter Bias: VTH = VCC, RTH = RB, IB = (VCC−VBE)/(RB+(β+1)RE), IC = β·IB, IE = (β+1)·IB, VE = IE·RE, VB = VE+VBE, VC = VCC−IC·RC, VCE = VC−VE
